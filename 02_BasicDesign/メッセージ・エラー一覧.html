ID体系 MSG-<区分>-nn。区分: CMN(共通) / AUTH(認証) / THEME / SRC(情報源) / NOTIF(通知設定) / ADMIN(管理者向け) / BATCH(バッチ/ログ) / SYS(システム)

画面・ログ・通知に出す文言を一元管理する。同じ意味は同じ文言（用語はユビキタス言語 §1 に従う）。実装ではメッセージリソース（messages.properties 等）に落とし、文言変更をコード修正なしで行えるようにする。種別: 情報 / 確認 / 警告 / エラー。日時は JST 表示。

1. 共通・一覧・入力（CMN）

ID 場面 種別 メッセージ 対応
MSG-CMN-01 一覧が0件（SC-02） 情報 該当する記事はありません。テーマを登録するか、条件を変えてお試しください。 FR-04
MSG-CMN-02 検索結果0件（SC-02） 情報 「{keyword}」に一致する記事は見つかりませんでした。 FR-04-03
MSG-CMN-03 必須未入力 エラー {項目名} を入力してください。 各入力
MSG-CMN-04 保存成功 情報 保存しました。 各画面
MSG-CMN-05 削除確認 確認 {対象} を削除します。よろしいですか？ 各画面
MSG-CMN-06 通信/処理失敗 エラー 処理に失敗しました。時間をおいて再度お試しください。（詳細はログを確認） §8
MSG-CMN-07 権限なし到達（user が admin 画面） エラー この画面は管理者専用です。アクセス権限がありません。 BD-SC-00-06

ID 場面 種別 メッセージ 対応

MSG-AUTH-03 PIN不一致 エラー PINが正しくありません。（残り {n} 回でロックされます） §8・FR-07-01
MSG-AUTH-04 連続失敗でロック 警告 連続して失敗したため、しばらくロックしました。{mm} 分後に再度お試しください。 §8
MSG-AUTH-05 新規登録の案内（SC-01/SC-10） 情報 新規登録は誰でも行えます（一般利用者として登録されます）。 FR-07-05
MSG-AUTH-06 自己登録の制約（SC-10） 情報 管理者アカウントの作成・権限変更は、管理者のみが行えます。 FR-07-05・FR-07-02

ID NotifyStatus 種別 メッセージ 再送/対応
MSG-ADMIN-01 ①TempError 警告 LINE側の一時障害で送信できませんでした。次回起動時に自動再送します。 次回再送
MSG-ADMIN-02 ②RateLimited 警告 送信が集中し一時的に失敗しました。次回起動時に再送します。 次回再送
MSG-ADMIN-03 ③AuthFailed エラー LINEトークンが無効です。設定を確認してください。 修正後の次回・5日超で打切
MSG-ADMIN-04 ③Blocked 警告 相手が未追加/ブロックの可能性があり、届いていません。 追加後の次回・5日超で打切
MSG-ADMIN-05 ④FormatError エラー メッセージ形式エラー（不具合）です。修正が必要です。 打ち切り（要修正）
MSG-ADMIN-06 ⑤Timeout 警告 応答がなく送信状況が不明です。冪等キーで二重を防ぎ再送します。 冪等キー付き再送
MSG-ADMIN-07 9:GaveUp 情報 打ち切りました（再送しません）。この新着はアプリ内「未通知」で確認できます。 FR-04-06
MSG-ADMIN-08 通数上限接近 警告 今月のLINE通数が上限に近づいています（{used}/200）。上限到達後はアプリ内表示に切り替わります。 FR-03-05
MSG-ADMIN-09 通数上限到達 警告 今月のLINE通数が上限に達しました。以降はアプリ内表示のみになります。 FR-03-05
MSG-ADMIN-10 LLMコスト接近 警告 今月のAI利用コストが上限に近づいています（¥{used}/¥500）。 NFR-06
MSG-ADMIN-11 LLMコスト到達 警告 AI利用コストが上限に達したため、LLM構造化を停止しました。RSSで収集は継続しています。 FR-02-11・FR-06-06

7. バッチ・ログ（BATCH）

主に SC-08 実行ログ・標準出力・CrawlLogs.error_message に記録（画面での恒常表示は最小限）。

ID 場面 種別 メッセージ（ログ） 対応
MSG-BATCH-01 収集成功 情報 収集完了: {source} 取得 {n}件 / 新規 {m}件。 CrawlStatus=Success
MSG-BATCH-02 一部失敗 警告 収集一部失敗: {source} — {理由}（該当分をスキップし継続）。 CrawlStatus=PartialError
MSG-BATCH-03 情報源失敗 エラー 収集失敗: {source} — {例外}。他情報源の収集は継続します。 CrawlStatus=Failed・NFR-10
MSG-BATCH-04 robotsスキップ 情報 robots.txt により取得をスキップ: {url}。 FR-02-05
MSG-BATCH-05 規約未確認スキップ 情報 規約未確認のため収集対象外: {source}。 FR-02-12
MSG-BATCH-06 LLMスキップ（予算） 警告 当月コスト上限のためLLM構造化をスキップ: {source}（RSS結果で登録）。 FR-02-11
MSG-BATCH-07 LLM構造化失敗 警告 構造化に失敗したため当該記事をスキップ: {url}。 §8
MSG-BATCH-08 重複スキップ 情報 既存記事のため登録スキップ（url_hash 一致）。 FR-02-08
MSG-BATCH-09 通知バッチ・対象なし 情報 未通知の新着はありません。 FR-03-01
MSG-BATCH-10 同日2回目 情報 本日は送信済みのため通知しません（{user}）。 FR-03-04
